GLaDOS / Repository

The [glados] package repository

GLaDOS runs an unmodified Arch Linux userland beside its kernel, and orange is how software gets into it. Orange is pacman with the verbs people expect: install, remove, update, upgrade, search. It reads all of Arch's repositories, and one of its own, which is this one.

[glados] carries what makes the userland GLaDOS: orange itself, the release files that make every program report it is running on GLaDOS, the key everything here is signed with, and the full desktop.

On GLaDOS

The ISO boots with a slim Linux system and orange already installed. Connect to the network and bring in the rest:

orange upgrade

That updates everything and installs glados-desktop: LibreOffice, GTK and Qt applications, a text editor, an image viewer and a media player, all opening in their own windows on the GLaDOS desktop. After that, anything else in Arch is one command away:

orange search editor
orange install fastfetch
orange info gimp

On any Arch Linux system

The repository is an ordinary signed pacman repository. Trust the key, then add it to /etc/pacman.conf:

curl -O https://repo.aperture.institute/glados.gpg
sudo pacman-key --add glados.gpg
sudo pacman-key --lsign-key 83E75C5B98F2579892AF3019AB32E9629000D4EC
[glados]
SigLevel = Required DatabaseRequired
Server = https://repo.aperture.institute/$arch

Then sudo pacman -Sy orange, and the same verbs work there too.

Every package and the database itself are signed, and pacman is told to require both. A package signed by any other key is refused, even inside a correctly signed database.
