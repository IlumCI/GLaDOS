GLaDOS archive

A file index in the shape of the mirrors this sort of thing used to be distributed from, back when the way you got an operating system was to find a directory listing at a university and hope it was nearby. The listing below is live; the files behind it are served from GitHub Releases, because GitHub Pages caps at 100 MB per file and would turn away every ISO here.

Sizes are what they are for reasons the ISO page explains: most of the 575 MB image is model weights, and even the 33 MB kernel-only image is at the smallest size FAT32 permits, which is not the smallest size the payload needs.

Every release carries a SHA256SUMS file. Checking it is worthwhile, since a truncated ISO still flashes and still boots before failing somewhere unrelated to the truncation.

If you only want the ISO, the download page has flashing instructions and hardware notes next to it.
