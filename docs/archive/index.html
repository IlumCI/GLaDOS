GLaDOS archive

Mirror-style file index for GLaDOS OS: bootable ISO images, source snapshots, documentation and SHA-256 checksums.

A file index in the shape of the mirrors this sort of thing used to be distributed from. Images are served from GitHub Releases — GitHub Pages caps at 100 MB per file and would reject every one of them.

If you only want the ISO, the download page has flashing instructions and hardware notes alongside it.
