Qwen3-0.6B in a kernel

Running Qwen3-0.6B inside an OS kernel: why its head dimension is stated rather than derived, what QK-Norm does, and why both fail without any error.

Qwen3-0.6B is the default model: 28 layers, 1024-dimensional residual stream, 16 query heads and 8 key/value heads, quantised to int8 for about 570 MB on disk.

It is not a Llama, and neither difference is loud

Head width is stated, not derived

Most implementations compute head dimension as dim / n_heads. For Qwen3 that gives 1024/16 = 64, and the correct answer is 128. The model states it independently, which means the query projection is 2048 wide against a 1024-wide residual stream — the attention path is deliberately wider than the thing it reads from.

Derive it instead and every weight tensor is reshaped wrong. The model still loads. It still runs. It generates confident nonsense.

QK-Norm

Qwen3 applies RMSNorm to each head's queries and keys, per head, before rotary embeddings. Omit it and the model remains numerically well-behaved and produces fluent text — just text from a network being fed activations it was never trained on.

How these get caught

Not by exceptions, because there are none. The checkpoint converter writes both facts into the file header so they travel with the weights rather than being inferred, and a NumPy reference implementation reads the converted file and produces logits to diff against. A converter bug shows up there too; only a kernel bug shows as a mismatch between the two.

The cheap end of the same check is reading the output. An instruction-tuned model whose attention path is wired correctly answers "what is the capital of France" with Paris.

Thinking tokens

Qwen3 reasons at length inside <think> blocks when left alone, which is the model working as designed and useless at a 64-token budget. The shell closes the block itself unless told not to. Whether the model has thinking tokens at all is decided by asking the tokenizer whether it knows <think> as a single token — a property of the vocabulary, rather than a guess from the model's name.
