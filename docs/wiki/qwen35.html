Qwen3.5 and the 2B distill

Qwen3.5 is a hybrid. Most of its layers use linear attention and a minority use ordinary softmax attention, which changes how a checkpoint has to be stored and how it has to be checked.

Three layers in four

In the published schedule, three layers out of every four carry linear attention and the fourth carries full attention. Grouping tensors by kind stops being possible, because there is no single stride to multiply: the layers are not interchangeable and the file has to be walked in layer order.

The schedule travels as an explicit bitmap in the header rather than being derived from an interval. A checkpoint that breaks the expected pattern then fails loudly at load instead of being silently misread as the pattern the reader assumed.

A format with no names in it

The body carries no names, shapes or lengths. That makes it compact and makes one class of bug extremely quiet: a writer and a reader that disagree about a single dimension leave everything after that point as perfectly valid floating point garbage.

So both readers walk and never seek, and both assert that they land exactly on the last byte. The converter makes the same bargain on the way in: every tensor is either written or explicitly skipped, and anything else is an error rather than a silent omission.

Mixture of experts is refused

The loader declines mixture-of-experts checkpoints outright. The smallest published one is 71.9 GB, nothing that size reaches a firmware pool on this laptop, and a forward pass for it could never be run or contradicted. Half implementing it would produce a code path that has never executed and cannot be tested, so it returns an unsupported error and says why.

Checking a hybrid without the hardware

The real 0.8B hybrid is 723 MB against the emulator's 516 MB synthetic disk, so a purpose-built small hybrid stands in. It is shaped to hit every path the real one does: both layer kinds, packed cache indices, partial rotary application, four value heads over two key heads, grouped queries, and an untied classifier. The generator prints what the logits should be.

Two switches make it a bisection tool rather than a pass or fail. Forcing the schedule to all-full or all-linear isolates the two mixers. Zeroing every projection back into the residual stream lets the loader, the final normalisation and the classifier be checked apart from any layer at all.

Where it runs

The 2B distill ships as a bootable image of about 1.9 GB. Guest memory has to cover the weights, because they are read whole into a pool before the firmware door closes, so the default allocation for emulation is raised accordingly. On the laptop it is a file on the boot partition and the same rules apply.
