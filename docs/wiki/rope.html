GLaDOS / Wiki / RoPE

RoPE

Rotary position embeddings encode position by rotating pairs of dimensions in the query and key vectors by an angle proportional to the position. Attention then depends on relative distance without any position vector being added anywhere.

Two conventions, one right answer per checkpoint

Which dimensions form a pair is a convention, and there are two in circulation.

The reference implementations most checkpoints are trained through pair dimension i with dimension i plus half the head width. The other convention, which appears in several compact C implementations, pairs adjacent dimensions: 0 with 1, 2 with 3, and so on.

Both rotate by the same angles. Both are norm preserving. Applying the wrong one produces no error, no NaN, no drift, and no complaint from any check that looks at magnitudes.

Why getting it wrong produces no error

Because a rotation is a rotation. The vectors keep their lengths, the attention scores stay in range, and the softmax behaves. What changes is which dimensions are being rotated together, so the model's notion of relative distance is scrambled in a way that is perfectly consistent and completely wrong.

A model in that state stays fluent. It writes grammatical sentences, keeps a topic for a while, and loses the thread slightly more than it should. That is indistinguishable from a small model being small, which is why this survived for a long time.

What it cost, measured

The interleaved convention was used here for months. On SmolLM2, the prompt asking for the capital of France produced "The capital of France." followed by blank lines. With the pairing corrected, the same prompt and the same checkpoint produced "The capital of France is Paris. Paris is a city known for" and continued sensibly.

Nothing else changed. No weights moved, no configuration was retuned. That is the entire evidence, and it is the reason the configuration now carries an explicit flag which is true only for genuine llama2.c checkpoints rather than being inferred from anything.

How to catch it

Ask for a fact the model should know and read the answer. That is a low-effort instrument and it detects this class of bug immediately, where every numeric sanity check available will pass. Comparing logits against a host-side reference on the same converted file is the precise version of the same idea.
