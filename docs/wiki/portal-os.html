Portal OS

Portal OS: not a theme pack, but a genuine ring-0 kernel named for GLaDOS, with Aperture Science styling and a language model in kernel space.

Search for a "Portal OS" and you mostly find themes: wallpapers, icon packs, a terminal colour scheme, occasionally a Linux distribution with the logo swapped. This is not that.

GLaDOS is an operating system in the literal sense — it boots on bare metal, brings up its own page tables, drives its own hardware, and has no Linux, no BSD and no kernel from anyone else underneath it. The Portal reference is in the name, the aesthetic, and one design joke. Everything else is an operating system.

What makes it Portal-ish

  • Named for the facility AI, and the resident model answers as it.
  • The Aperture visual language: amber on black, monospace, vector-drawn logo at boot.
  • A tone that treats catastrophic failure as a procedural note.

What makes it an operating system

LayerWhat is there
BootIts own UEFI application; no GRUB, no shim, no Linux
MemoryPhysical frame allocator and hand-built page tables
SchedulingPreemptive multitasking on an APIC timer
DriversNVMe, Intel e1000, Realtek RTL8168, xHCI USB 3
NetworkIts own ARP, IPv4, ICMP, UDP, TCP, DHCP, DNS, TLS 1.3
CryptoIts own SHA-2, AES, ChaCha20, X25519, RSA, ECDSA
GraphicsIts own compositor and window manager
AIIts own transformer inference, in kernel space

The only code in it that was not written for this project is Rust's core library, and 509 hardware constants transcribed from Linux because there is no other source for them.
