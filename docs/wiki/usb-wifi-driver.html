USB WiFi on bare metal

Why the laptop's built-in WiFi cannot work, how a USB dongle sidesteps it, and why the RTL8188EU init tables were transcribed rather than written.

Wireless is the one major subsystem that does not work, and the reason is worth explaining because it is not a matter of effort.

CNVi: the card is not a card

The laptop's built-in wireless is CNVi, Intel's split architecture. The MAC — the part that would need a driver — lives in the chipset, and the M.2 module is only a radio. Talking to it requires an undocumented signed-firmware protocol that is not published anywhere.

So the kernel's wireless module identifies the hardware and refuses to pretend it can drive it. The WPA2 supplicant is complete, implements the four-way handshake, and passes IEEE 802.11i test vectors at every boot — and has never had a radio to run on.

A USB dongle sidesteps all of it

A USB wireless adapter is a complete radio and MAC behind a bus the kernel now drives. The target is a Realtek RTL8188EU.

It has no memory-mapped registers at all. Every register is a vendor control transfer, so a single register read is a full USB round trip of a few hundred microseconds — a fact that shapes the entire driver, since anything that polls a register in a loop is far slower than it looks.

Why the tables were copied, and why that is stated

Bringing up the chip needs a power-on sequence, PHY and radio initialisation tables, and an efuse layout: 509 specific register/value pairs that exist in Realtek's vendor driver and in Linux's rtl8xxxu, and nowhere else.

They were transcribed from Linux rather than written, and mechanically rather than by hand — 509 hex pairs retyped by a human contain errors at some rate, and an error here does not fail loudly. A wrong AGC value costs sensitivity; a wrong PHY value skews a filter. Both present as "wireless is a bit unreliable."

Those constants are GPL-2.0 and are kept in a single file, marked as such. They are the only code in this kernel that was not written for it, apart from Rust's core. Saying so is cheaper than a blanket claim that quietly covers someone else's work.

Order is content

The AGC table writes the same register 130 times, with the index encoded in the value. Sorting or deduplicating it produces a different table that still looks entirely reasonable.
