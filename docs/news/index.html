How versions work here

Images are named for the release that built them, so glados-1.2.27.iso and glados-1.2.26.iso can sit in the same folder without one silently overwriting the other. That naming arrived at 1.2.26 and immediately broke every download link on this site, which had been written against the older unversioned names and went on describing them confidently for two releases. The download table is generated from the release list now, and tools/site.py --check fetches every link it offers.

Releases before 1.2.26 carry unversioned image names and fewer images: the 8k and 32k context variants did not exist, and neither did the 2B model before 1.1.0.
